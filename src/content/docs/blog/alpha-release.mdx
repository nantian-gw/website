We're pleased to announce the **v2026.08.0-alpha.1** release — the first alpha in the August 2026 cycle. This release includes significant improvements across all components since the v2026.06.0 GA.

## What's New

### Delta xDS

The control plane now supports **incremental configuration delivery** (Delta xDS) alongside the existing State-of-the-World (SotW) protocol. This reduces bandwidth and latency for configuration updates by sending only the changed resources.

- Diff engine (`delta_diff.go`) computes per-resource changes
- gRPC handler (`delta_server.go`) streams DeltaDiscoveryResponses
- Rust client (`delta.rs`) processes delta updates
- Feature-gated behind `xdsProtocol: "delta"` in the gateway config

### Conformance

We've reached **594+ passing tests with 0 failures** in the Gateway API conformance suite. The only skipped tests are mesh-related (infrastructure not deployed in Kind clusters).

Key improvements:
- **BackendTLSPolicy** and **BackendTLSPolicyConflictResolution** — unskipped and passing
- **ListenerSetAllowedRoutesSupportedKinds** — unskipped and passing
- Conflict retry loop patched into upstream `apply.go` for resourceVersion conflicts

### Platform & Infrastructure

- **Docker builds** now support version tags; pushing a `v*` tag triggers image builds with the corresponding tag
- **Helm chart** published to `https://chart.nantian.dev` automatically on version tags
- **Release automation** with `resolve-release.sh`, `validate-release`, and `publish-release` workflows
- **Version pattern** updated to support `-alpha.x` and `-beta.x` suffixes

### Quality of Life

- **WebSocket large-payload test** stabilized with retry logic for transient `BrokenPipe` errors
- **Lint hygiene**: goconst threshold adjusted, constants extracted in `resource_kinds.go`
- **Dashboard Docker build**: fixed `.dockerignore` context path
- **Dataplane**: global allocator fix for benchmark tests, CI skip removed
- **goconst** `min-occurrences` raised from 4 to 6, reducing noise by 72%

## Installation

```bash
# Add the Helm repository
helm repo add nantian-gw https://chart.nantian.dev
helm repo update

# Install the alpha release
helm install nantian-gw nantian-gw/nantian-gw \
  --version 0.4.0-alpha.1 \
  --namespace nantian-gw \
  --create-namespace
```
